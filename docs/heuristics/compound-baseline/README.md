# Compound parity baseline

This gate preserves 25 seeded graphs in all four directions: 100 inputs, each
with two groups of 2–4 leaves, one root leaf, varied dimensions, internal DAG
edges and at least one cross-boundary edge. No failed graph is resampled.
This first hierarchy corpus does not yet cover explicit ports, labels, cycles,
ancestor endpoints or deeper nesting; existing oracle tests retain those cases.
It supplements the broader parity work, rather than replacing it.

Run `pnpm test:parity:compound [report-path]`. Exit status is **1 until every
case matches** real elkjs 0.11.1. The default report is ignored scratch output;
the checked-in report is the initial baseline. Geometry comparisons use the
same absolute 5e-13 tolerance as the existing 12-decimal oracle tests. Bounds,
node/port/label geometry, edge endpoint ownership, container ownership,
sections, bends, junctions and section connectivity are checked. Runtime
metadata and generated section identifiers are omitted. Both engine errors
fail the gate, even if their messages happen to match.

At native source commit `93293b08a4f6e417730934028c03a32161a3ae6c`:
**0/100 complete matches**, **5,612 differing values**, zero engine errors. All 100 have numeric geometry
differences independently of container metadata.
[The full report](./report.json) preserves inputs, both outputs and every
comparison difference. [The visual comparison](./index.html) renders all 100
pairs with identical viewports and scale; no routes are repaired for display.

## First differing foundation

[Real ELK's phase capture](./worker-phases.json), generated by
`scripts/parity/trace-compound-worker.mjs`, observes the installed unmodified
worker through the real ELK API. The observer delegates every wrapped call
unchanged. It records 63 stages over three scopes for RIGHT seed 1.

ELK calls `doCompoundLayout` rather than the flat `doLayout` entry. It processes
scopes bottom-up between shared phase boundaries, without `ComponentsProcessor`
splitting/packing each scope. Native currently recursively performs complete
flat layouts using ordinary zero-size proxy nodes, then repairs sibling order
and routes in the compatibility adapter.

The trace exposes the concrete external-port contract: the child scope contains
an `EXTERNAL_PORT` dummy with a WEST input port. ELK introduces a LONG_EDGE
segment, preserves both distinct EAST ports on n0 (y=13.333… and 26.666…),
positions the external dummy on its compound boundary and transfers its geometry
to the compound port before laying out the root. The root g0 port is (119,52),
with g0 size (114,65.666…). Native instead synthesizes a port from the descendant
rectangle midpoint; this loses the actual selected endpoint and internal route.

The retained [component experiment](./rejected-component-experiment.patch)
disabled component packing in compound scopes and removed the model-order
sibling repair. It improved seed 1's relative group order, but still matched
0/100 graphs and broke an existing explicit-port oracle case (root height
88.666… versus 96). The experiment was reverted. No assertion was weakened.

The next implementation must preserve native external-port dummy identity,
separate-layer constraints, internal route sections and parent-port transfer,
then schedule hierarchy phases together. Disabling packing alone is insufficient.
The public native compound solver and compatibility adapter must converge on
that foundation; changing only exported endpoint coordinates cannot establish
layout/routing parity.

Validation for this diagnostic change: source/repository TypeScript and selected
lint pass; 28 existing hierarchy/component and gate-guard tests pass after reverting the
experiment. The new 100-case gate fails intentionally and must remain required
parity work. The broad suite was not rerun: production source is unchanged.

Regenerate the trace:

```sh
node scripts/parity/trace-compound-worker.mjs docs/heuristics/compound-baseline/report.json docs/heuristics/compound-baseline/worker-phases.json
node scripts/parity/render-compound-baseline.mjs
```
